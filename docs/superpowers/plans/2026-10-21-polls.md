# 투표(Polls) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 채팅방에서 카카오톡 수준의 투표(한 개/여러 개 선택, 익명, 선택지 추가, 마감 시각)를 만들고 실시간으로 함께 본다.

**Architecture:** 투표는 `messages.poll_id`로 연결된 일반 메시지(`kind='user'`, content `"(투표) 질문"`)라서 목록·푸시·검색·답장이 그대로 동작한다. 투표 데이터는 `polls`/`poll_options`/`poll_votes` 세 테이블에 두고 테이블 grant 없이 security definer RPC로만 읽고 쓴다(익명 보장). 쓰기 RPC는 `poll_updated {roomId, pollId}`를 방 채널로 보내고, 카드마다 `usePoll`이 그 투표만 다시 받는다.

**Tech Stack:** Supabase Postgres(RLS, plpgsql, pgTAP, Realtime broadcast) · Next.js 16 / React 19 / TanStack Query v5 · node:test

**Spec:** `docs/superpowers/specs/2026-10-21-polls-design.md` (Codex 검토: `docs/superpowers/specs/2026-10-21-polls-review-codex.md`)

## Global Constraints

- 질문 trim 후 1~100자, 선택지 trim 후 1~50자, 선택지 2~20개, 마감 시각은 지금+1분 이후.
- 정리 규칙(서버·클라 동일): 연속 공백을 한 칸으로 바꾸고 앞뒤 공백 제거, 빈 값 제거, 대소문자 무시 중복 제거(첫 등장 유지).
- 익명 투표는 만든 사람을 포함해 누구에게도 투표자를 돌려주지 않는다. `poll_votes`는 어떤 역할도 직접 select할 수 없다.
- 함수: `security definer` + `set search_path = ''` + 스키마 한정 이름, `revoke execute ... from public, anon`(public RPC는 `grant ... to authenticated`, private 함수는 `authenticated`에서도 revoke).
- 에러: `raise exception '<CODE>' using hint = '<한국어 사용자 메시지>'`. 새 코드 `POLL_NOT_FOUND`, `POLL_CLOSED`. 그 외 `VALIDATION_FAILED`, `CHAT_FORBIDDEN`.
- 쓰기 RPC 잠금 순서: 연결 메시지 행 `for update` → polls 행 `for update` → 열림 판정.
- `client/src/lib/supabase/database.types.ts`는 손으로 관리하는 압축 형식. **재생성 금지**, 직접 추가.
- 파일 편집은 기존 줄바꿈(CRLF/LF)을 유지한다. 커밋 메시지는 파일로 쓰고 `git commit -F`(PowerShell 따옴표 문제), 끝줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 색은 토큰만(`bg-primary`, `text-muted-foreground` …), 새 버튼은 `pressable`, 서버 요청 버튼은 `<Button loading>`, 확인은 `confirm()`, 시트는 `components/ui/sheet.tsx`. 새 의존성 추가 금지.
- React 19 lint: effect 본문 동기 setState 금지, 렌더 중 `Date.now()`/`new Date()` 금지(이벤트 핸들러·effect·useState 초기화 함수 안에서만).

## Review Focus

1. **한 개 선택 투표에서 다른 줄을 누름** → 이전 선택이 빠지고 새 줄로 옮겨야 한다(표 2개가 되면 안 됨). Task 4 `nextChoice`·`withMyVote` 테스트, Task 2 pgTAP "옮기기".
2. **보고 있는 중에 마감 시각이 지남** → 새로고침 없이 카드가 "마감됨"으로 바뀌고 누를 수 없어야 한다. Task 4 `isClosed`/`pollMeta` 테스트(now 인자), Task 6 타이머.
3. **투표 메시지 삭제 직후 다른 사람이 누름** → 서버가 `POLL_CLOSED`, 화면은 낙관적 표시를 되돌리고 토스트. Task 3 pgTAP, Task 6 `onError` 롤백.
4. **선택지에 공백만 다르거나 대소문자만 다른 값 입력**(`" 짜장 "`, `"짜장"`) → 하나로 합쳐져야 하고 서버·클라 판정이 같아야 한다("만들기" 버튼 활성 판단). Task 1 pgTAP, Task 4 `cleanOptions` 테스트.
5. **로컬 시각으로 고른 마감 시각** → 서버에는 UTC ISO로 가고 화면 표시는 기기 시간대로 같은 시각이어야 한다. Task 4 `toLocalInput` 왕복 테스트.

```sql
-- 투표(스펙 docs/superpowers/specs/2026-10-21-polls-design.md).
-- 투표는 messages.poll_id로 연결된 일반 메시지(kind 'user', content '(투표) 질문')라 목록·푸시·검색·답장이 그대로 동작한다.
-- 세 테이블은 grant가 없다 — 읽기·쓰기는 RPC로만(익명 투표의 투표자를 누구도 직접 읽지 못하게).
create table public.polls (
  id bigint generated always as identity primary key,
  room_id bigint not null references public.chat_rooms (id) on delete cascade,
  creator_id uuid references public.profiles (id) on delete set null,
  question text not null constraint polls_question_length check (char_length(question) between 1 and 100),
  multiple boolean not null default false,
  anonymous boolean not null default false,
  allow_add boolean not null default false,
  closes_at timestamptz,
  closed_at timestamptz,
  created_at timestamptz not null default now()
);
create index polls_room_id_idx on public.polls (room_id);
create index polls_creator_id_idx on public.polls (creator_id);

create table public.poll_options (
  id bigint generated always as identity primary key,
  poll_id bigint not null references public.polls (id) on delete cascade,
  label text not null constraint poll_options_label_length check (char_length(label) between 1 and 50),
  added_by uuid references public.profiles (id) on delete set null,
  created_at timestamptz not null default now()
);
create unique index poll_options_label_key on public.poll_options (poll_id, lower(label));
create index poll_options_added_by_idx on public.poll_options (added_by);

create table public.poll_votes (
  poll_id bigint not null references public.polls (id) on delete cascade,
  option_id bigint not null references public.poll_options (id) on delete cascade,
  user_id uuid not null references public.profiles (id) on delete cascade, -- 탈퇴하면 표도 사라진다
  created_at timestamptz not null default now(),
  primary key (poll_id, option_id, user_id)
);
create index poll_votes_option_id_idx on public.poll_votes (option_id);
create index poll_votes_user_id_idx on public.poll_votes (user_id);

alter table public.polls enable row level security;
alter table public.poll_options enable row level security;
alter table public.poll_votes enable row level security;
revoke all on table public.polls, public.poll_options, public.poll_votes from anon, authenticated;

-- 방 삭제 때 messages·polls가 같은 cascade로 지워지므로 기본 FK(no action)로 충분하다.
-- 사용자 insert grant(room_id, content, reply_to_id …)에 poll_id는 없다 → create_poll만 넣는다.
alter table public.messages add column poll_id bigint references public.polls (id);
create index messages_poll_id_idx on public.messages (poll_id) where poll_id is not null;

-- ============ 헬퍼 ============
-- 질문·선택지 정리: 연속 공백 → 한 칸, 앞뒤 공백 제거(클라 lib/polls.ts normalizeLabel과 같은 규칙)
create or replace function private.normalize_label(p_text text) returns text
language sql immutable set search_path = ''
as $$
  select btrim(regexp_replace(p_text, '\s+', ' ', 'g'));
$$;
revoke execute on function private.normalize_label(text) from public, anon, authenticated;

-- 열림: 일찍 마감 안 했고, 마감 시각 전이고, 투표 메시지가 삭제되지 않았다
create or replace function private.poll_open(p_poll public.polls) returns boolean
language sql stable set search_path = ''
as $$
  select p_poll.closed_at is null
     and (p_poll.closes_at is null or p_poll.closes_at > now())
     and exists (select 1 from public.messages m where m.poll_id = p_poll.id and m.deleted_at is null);
$$;
revoke execute on function private.poll_open(public.polls) from public, anon, authenticated;

-- ============ RPC ============
create or replace function public.create_poll(
  p_room_id bigint, p_question text, p_options text[],
  p_multiple boolean, p_anonymous boolean, p_allow_add boolean, p_closes_at timestamptz
) returns bigint
language plpgsql security definer set search_path = ''
as $$
declare
  v_question text := private.normalize_label(coalesce(p_question, ''));
  v_options text[];
  v_poll_id bigint;
  v_message_id bigint;
begin
  perform private.require_active_session();
  if not private.is_room_member(p_room_id) then
    raise exception 'CHAT_FORBIDDEN' using hint = '참여 중인 방이 아닙니다.';
  end if;
  if char_length(v_question) not between 1 and 100 then
    raise exception 'VALIDATION_FAILED' using hint = '질문은 1~100자여야 해요.';
  end if;
  -- 정리 → 빈 값 제거 → 대소문자 무시 중복 제거(첫 등장 유지)
  select coalesce(array_agg(label order by ord), '{}') into v_options
  from (
    select distinct on (lower(label)) label, ord
    from (select private.normalize_label(x) as label, ord
          from unnest(coalesce(p_options, '{}')) with ordinality as t(x, ord)) s
    where label <> ''
    order by lower(label), ord
  ) d;
  if cardinality(v_options) not between 2 and 20 then
    raise exception 'VALIDATION_FAILED' using hint = '항목은 2~20개여야 해요.';
  end if;
  if exists (select 1 from unnest(v_options) l where char_length(l) > 50) then
    raise exception 'VALIDATION_FAILED' using hint = '항목은 50자까지 쓸 수 있어요.';
  end if;
  if p_closes_at is not null and p_closes_at < now() + interval '1 minute' then
    raise exception 'VALIDATION_FAILED' using hint = '마감 시각은 1분 뒤부터 고를 수 있어요.';
  end if;

  insert into public.polls (room_id, creator_id, question, multiple, anonymous, allow_add, closes_at)
  values (p_room_id, auth.uid(), v_question, coalesce(p_multiple, false), coalesce(p_anonymous, false),
          coalesce(p_allow_add, false), p_closes_at)
  returning id into v_poll_id;
  insert into public.poll_options (poll_id, label, added_by)
  select v_poll_id, l, auth.uid() from unnest(v_options) with ordinality as t(l, ord) order by ord;
  -- 메시지 insert 트리거가 기존처럼 broadcast·푸시를 처리한다
  insert into public.messages (room_id, sender_id, content, poll_id)
  values (p_room_id, auth.uid(), '(투표) ' || v_question, v_poll_id)
  returning id into v_message_id;
  return v_message_id;
end;
$$;
revoke execute on function public.create_poll(bigint, text, text[], boolean, boolean, boolean, timestamptz) from public, anon;
grant execute on function public.create_poll(bigint, text, text[], boolean, boolean, boolean, timestamptz) to authenticated;

-- 투표 하나. 익명이면 voters는 만든 사람에게도 항상 []. 삭제된 투표는 결과도 주지 않는다.
create or replace function public.get_poll(p_poll_id bigint) returns jsonb
language plpgsql security definer set search_path = ''
as $$
declare
  v_poll public.polls;
  v_message_id bigint;
begin
  perform private.require_active_session();
  select * into v_poll from public.polls where id = p_poll_id;
  select id into v_message_id from public.messages where poll_id = p_poll_id and deleted_at is null;
  if v_poll.id is null or v_message_id is null or not private.is_room_member(v_poll.room_id) then
    raise exception 'POLL_NOT_FOUND' using hint = '투표를 찾을 수 없어요.';
  end if;
  return jsonb_build_object(
    'id', v_poll.id, 'roomId', v_poll.room_id, 'messageId', v_message_id, 'creatorId', v_poll.creator_id,

    'myOptionIds', coalesce((select jsonb_agg(option_id order by option_id) from public.poll_votes
                             where poll_id = p_poll_id and user_id = auth.uid()), '[]'::jsonb),
    'options', coalesce((
      select jsonb_agg(jsonb_build_object(
               'id', o.id, 'label', o.label,
               'count', (select count(*) from public.poll_votes v where v.option_id = o.id),
               'voters', case when v_poll.anonymous then '[]'::jsonb else coalesce((
                   select jsonb_agg(private.display_name(v.user_id) order by v.created_at, v.user_id)
                   from public.poll_votes v where v.option_id = o.id), '[]'::jsonb) end
             ) order by o.id)
      from public.poll_options o where o.poll_id = p_poll_id), '[]'::jsonb));
end;
$$;
revoke execute on function public.get_poll(bigint) from public, anon;
grant execute on function public.get_poll(bigint) to authenticated;
```

```sql
-- 투표 쓰기(스펙 §3.2~3.4)
-- 잠금 순서: 투표 메시지 → 투표. delete_message도 메시지 행을 먼저 잠그므로 삭제와 투표 쓰기가 엇갈리지 않는다.
create or replace function private.lock_poll(p_poll_id bigint, p_require_open boolean) returns public.polls
language plpgsql security definer set search_path = ''
as $$
declare
  v_poll public.polls;
begin
  perform 1 from public.messages where poll_id = p_poll_id for update;
  select * into v_poll from public.polls where id = p_poll_id for update;
  if not found or not private.is_room_member(v_poll.room_id) then
    raise exception 'POLL_NOT_FOUND' using hint = '투표를 찾을 수 없어요.';
  end if;
  if p_require_open and not private.poll_open(v_poll) then
    raise exception 'POLL_CLOSED' using hint = '마감된 투표예요.';
  end if;
  return v_poll;
end;
$$;
revoke execute on function private.lock_poll(bigint, boolean) from public, anon, authenticated;

-- 표 수·투표자는 싣지 않는다(받은 쪽이 get_poll로 다시 받는다)
create or replace function private.poll_broadcast(p_poll public.polls) returns void
language sql security definer set search_path = ''
as $$
  select private.broadcast('room:' || p_poll.room_id, 'poll_updated',
    jsonb_build_object('roomId', p_poll.room_id, 'pollId', p_poll.id));
$$;
revoke execute on function private.poll_broadcast(public.polls) from public, anon, authenticated;

-- p_option_ids = 내 최종 선택(빈 배열 = 취소). 중복·null은 정리한다.
create or replace function public.vote_poll(p_poll_id bigint, p_option_ids bigint[]) returns void
language plpgsql security definer set search_path = ''
as $$
declare
  v_poll public.polls;
  v_ids bigint[];
begin
  perform private.require_active_session();
  v_poll := private.lock_poll(p_poll_id, true);
  select coalesce(array_agg(distinct x), '{}') into v_ids from unnest(coalesce(p_option_ids, '{}')) x where x is not null;
  if not v_poll.multiple and cardinality(v_ids) > 1 then
    raise exception 'VALIDATION_FAILED' using hint = '하나만 고를 수 있어요.';
  end if;
  if exists (select 1 from unnest(v_ids) x
             where not exists (select 1 from public.poll_options o where o.id = x and o.poll_id = p_poll_id)) then
    raise exception 'VALIDATION_FAILED' using hint = '항목을 찾을 수 없어요.';
  end if;
  delete from public.poll_votes where poll_id = p_poll_id and user_id = auth.uid();
  insert into public.poll_votes (poll_id, option_id, user_id) select p_poll_id, x, auth.uid() from unnest(v_ids) x;
  perform private.poll_broadcast(v_poll);
end;
$$;
revoke execute on function public.vote_poll(bigint, bigint[]) from public, anon;
grant execute on function public.vote_poll(bigint, bigint[]) to authenticated;

create or replace function public.add_poll_option(p_poll_id bigint, p_label text) returns bigint
language plpgsql security definer set search_path = ''
as $$
declare
  v_poll public.polls;
  v_label text := private.normalize_label(coalesce(p_label, ''));
  v_id bigint;
begin
  perform private.require_active_session();
  v_poll := private.lock_poll(p_poll_id, true);
  if v_poll.creator_id is distinct from auth.uid() and not v_poll.allow_add then
    raise exception 'CHAT_FORBIDDEN' using hint = '항목을 추가할 수 없는 투표예요.';
  end if;
  if char_length(v_label) not between 1 and 50 then
    raise exception 'VALIDATION_FAILED' using hint = '항목은 1~50자여야 해요.';
  end if;
  if (select count(*) from public.poll_options where poll_id = p_poll_id) >= 20 then
    raise exception 'VALIDATION_FAILED' using hint = '항목은 20개까지예요.';
  end if;
  begin
    insert into public.poll_options (poll_id, label, added_by) values (p_poll_id, v_label, auth.uid()) returning id into v_id;
  exception when unique_violation then
    raise exception 'VALIDATION_FAILED' using hint = '이미 있는 항목이에요.';
  end;
  perform private.poll_broadcast(v_poll);
  return v_id;
end;
$$;
revoke execute on function public.add_poll_option(bigint, text) from public, anon;
grant execute on function public.add_poll_option(bigint, text) to authenticated;

-- 만든 사람만. 이미 닫혔거나(시각 경과·삭제 포함) 다시 부르면 아무 일도 하지 않는다(broadcast도 없음).
create or replace function public.close_poll(p_poll_id bigint) returns void
language plpgsql security definer set search_path = ''
as $$
declare
  v_poll public.polls;
begin
  perform private.require_active_session();
  v_poll := private.lock_poll(p_poll_id, false);
  if v_poll.creator_id is distinct from auth.uid() then
    raise exception 'CHAT_FORBIDDEN' using hint = '만든 사람만 마감할 수 있어요.';
  end if;
  if not private.poll_open(v_poll) then
    return;
  end if;
  update public.polls set closed_at = now() where id = p_poll_id;
  perform private.poll_broadcast(v_poll);
end;
$$;
revoke execute on function public.close_poll(bigint) from public, anon;
grant execute on function public.close_poll(bigint) to authenticated;
```

```ts
import type { Poll } from "../types/domain.ts";

// 투표 규칙(서버 create_poll·add_poll_option과 같은 값·같은 정리 규칙)
export const POLL_QUESTION_MAX = 100;
export const POLL_LABEL_MAX = 50;
export const POLL_OPTIONS_MAX = 20;

// 연속 공백 → 한 칸, 앞뒤 공백 제거(private.normalize_label)
export const normalizeLabel = (s: string): string => s.replace(/\s+/g, " ").trim();

// 빈 칸 제거, 대소문자 무시 중복 제거(첫 등장 유지)
export const cleanOptions = (list: string[]): string[] => {
  const seen = new Set<string>();
  return list.map(normalizeLabel).filter((label) => {
    const key = label.toLowerCase();
    if (!label || seen.has(key)) return false;
    seen.add(key);
    return true;
  });
};

// 줄을 눌렀을 때 내 새 선택. 한 개 선택: 같은 줄이면 취소, 아니면 옮기기. 여러 개: 토글.
export const nextChoice = (mine: number[], optionId: number, multiple: boolean): number[] =>
  mine.includes(optionId) ? mine.filter((id) => id !== optionId) : multiple ? [...mine, optionId] : [optionId];

// 응답 전 화면에 먼저 반영(표 수·참여자 수·내 선택). 투표자 이름은 서버 응답으로 갱신된다.
export const withMyVote = (poll: Poll, next: number[]): Poll => {
  const before = new Set(poll.myOptionIds);
  const after = new Set(next);
  return {
    ...poll,
    myOptionIds: next,
    voterCount: poll.voterCount + (after.size > 0 ? 1 : 0) - (before.size > 0 ? 1 : 0),
    options: poll.options.map((o) => ({ ...o, count: o.count + (after.has(o.id) ? 1 : 0) - (before.has(o.id) ? 1 : 0) })),
  };
};

// 최종 판정은 서버. 화면은 마감 시각이 지나면 바로 닫힌 것으로 그린다.
export const isClosed = (poll: Poll, now: Date): boolean =>
  poll.closed || (poll.closesAt !== null && new Date(poll.closesAt).getTime() <= now.getTime());

const pad = (n: number) => String(n).padStart(2, "0");

// 카드 머리 작은 글씨: "익명 · 여러 개 선택 · 10/22 18:05 마감" / 마감되면 마지막이 "마감됨"
export const pollMeta = (poll: Poll, now: Date): string => {
  const at = poll.closesAt ? new Date(poll.closesAt) : null;
  const end = isClosed(poll, now)
    ? "마감됨"
    : at && `${at.getMonth() + 1}/${at.getDate()} ${pad(at.getHours())}:${pad(at.getMinutes())} 마감`;
  return [poll.anonymous && "익명", poll.multiple && "여러 개 선택", end].filter(Boolean).join(" · ");
};

// <input type="datetime-local"> 값(기기 시간대, 시간대 표기 없음). 보낼 때는 new Date(value).toISOString().
export const toLocalInput = (d: Date): string =>
  `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}`;
```

주의: 마감된 투표에서 `pollMeta`는 "익명 · 마감됨"처럼 앞부분을 유지한다. 테스트의 `poll({ closesAt })`는 익명·여러 개가 아니므로 "마감됨" 단독이다.

```ts
"use client";

import { useEffect } from "react";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { toast } from "sonner";
import { useChat } from "@/components/chat-provider";
import { getErrorMessage } from "@/lib/error-handler";
import { withMyVote } from "@/lib/polls";
import { addPollOption, closePoll, getPoll, votePoll } from "@/services/polls";
import type { DomainError, Poll } from "@/types/domain";

const pollKey = (pollId: number) => ["poll", pollId] as const;
const fail = (e: unknown) => toast.error(getErrorMessage(e as unknown as DomainError));

// 투표 카드 하나. 이 투표의 poll_updated와 재구독(놓친 이벤트) 때 다시 받는다.
export const usePoll = (roomId: number, pollId: number) => {
  const queryClient = useQueryClient();
  const { onRoomEvent } = useChat();
  const query = useQuery({ queryKey: pollKey(pollId), queryFn: () => getPoll(pollId) });

  useEffect(
    () =>
      onRoomEvent((e) => {
        if (e.roomId !== roomId) return;
        if ((e.type === "poll_updated" && e.pollId === pollId) || e.type === "subscribed") {
          void queryClient.invalidateQueries({ queryKey: pollKey(pollId) });
        }
      }),
    [roomId, pollId, onRoomEvent, queryClient],
  );

  const refresh = () => queryClient.invalidateQueries({ queryKey: pollKey(pollId) });

  // 누르자마자 표시하고, 실패하면 되돌린다
  const vote = useMutation({
    mutationFn: (next: number[]) => votePoll(pollId, next),
    onMutate: async (next) => {
      await queryClient.cancelQueries({ queryKey: pollKey(pollId) });
      const prev = queryClient.getQueryData<Poll>(pollKey(pollId));
      if (prev) queryClient.setQueryData<Poll>(pollKey(pollId), withMyVote(prev, next));
      return { prev };
    },
    onError: (e, _next, ctx) => {
      if (ctx?.prev) queryClient.setQueryData(pollKey(pollId), ctx.prev);
      fail(e);
    },
    onSettled: refresh,
  });
  const add = useMutation({ mutationFn: (label: string) => addPollOption(pollId, label), onSuccess: refresh, onError: fail });
  const close = useMutation({ mutationFn: () => closePoll(pollId), onSuccess: refresh, onError: fail });

  return {
    poll: query.data ?? null,
    isError: query.isError,
    vote: vote.mutate,
    addOption: add.mutateAsync,
    adding: add.isPending,
    close: () => close.mutate(),
    closing: close.isPending,
  };
};
```
