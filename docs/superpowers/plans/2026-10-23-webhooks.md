# 수신 웹훅 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 외부 스크립트가 `POST /functions/v1/webhook`(Bearer 토큰)으로 그룹 방에 봇 이름의 메시지를 올리고, 말풍선 속 링크를 누를 수 있게 한다.

**Architecture:** 봇 = 로그인 불가 `auth.users` 행 + `profiles.is_bot`. 웹훅 = `private.webhooks`(토큰 sha256 해시). SQL Editor 전용 관리 함수와 service_role 전용 `webhook_post`. Edge Function은 토큰 형식 검사·2,000자 분할만 하고 DB 함수를 부른다. 실시간·푸시는 기존 메시지 트리거가 처리.

**Tech Stack:** Supabase Postgres(pgTAP), Edge Function(Deno, supabase-js `npm:@supabase/supabase-js@2.117.2`), Next.js 16 / React 19, node:test

**Spec:** `docs/superpowers/specs/2026-10-23-webhooks-design.md` (Codex 검토: `2026-10-23-webhooks-review-codex.md`)

## Global Constraints

- 마이그레이션만으로 DB 변경. 새 함수는 `security definer` + `set search_path = ''` + 스키마 한정 이름.
- 관리 함수(`create_webhook` 2개, `rotate_webhook`, `delete_webhook`): `revoke execute ... from public, anon, authenticated, service_role`.
- `webhook_post`: `revoke ... from public, anon, authenticated` 후 `grant execute ... to service_role`만.
- 토큰 = `'dch_' || encode(extensions.gen_random_bytes(32), 'hex')`, 저장은 `encode(extensions.digest(token, 'sha256'), 'hex')`만.
- 봇 username = `'bot_' || substr(replace(id::text, '-', ''), 1, 16)`.
- 웹훅 이름: trim 후 1~20자. 메시지 조각: 1~2,000자, 최대 10개. Edge 전체 본문: 20,000자 초과 413.
- 에러: 새 코드 `WEBHOOK_INVALID`(hint `'웹훅 토큰이 올바르지 않습니다.'`), 그 밖은 기존 `VALIDATION_FAILED`.
- 시스템 메시지 문구: `<봇이름>님이 들어왔어요` / `<봇이름>님이 나갔어요`.
- Vercel 환경 변수 변경 없음. Edge Function에 새 비밀 없음.
- 클라이언트 CRLF 파일은 CRLF 유지, 마이그레이션·pgTAP은 LF. `database.types.ts`는 수정 불필요(클라이언트가 새 칼럼·RPC를 안 씀).
- 클라이언트 색은 토큰만(`text-*` hex 금지). 새 UI 의존성 없음.

## Review Focus

1. 봇만 남은 방 / 방장이 먼저 나간 방 → 사람에게 방장이 넘어가고, 사람이 0명이면 방이 사라져야 함 (Task 1 테스트)
2. 강퇴된 봇의 토큰 → 401, 메시지 안 들어감 (Task 2 테스트)
3. 한 줄이 2,000자를 넘거나 이모지(서로게이트 쌍)가 경계에 걸린 본문 → 글자가 깨지지 않고 DB `char_length` 검사를 통과 (Task 3 테스트)
4. `https://a.com/x.`, `(https://a.com)`, `…/Foo_(bar)` 같은 주소 → 끝 문장부호·바깥 괄호 제외 (Task 4 테스트)
5. 링크 위 길게 누르기 → 메뉴가 뜨고 링크는 열리지 않음(`a`가 `ignoresLongPress` 대상이 아님) (Task 4 테스트)
